🧪 Wallet Connection Test Suite

Task 11.1: Test wallet connection with all providers
Requirements: 1.1, 1.2, 1.3, 1.4

Test Environment Setup:
Before running these tests, ensure you have the following wallet extensions installed:
  • Phantom Wallet (phantom.app)
  • Backpack Wallet (backpack.app)
  • Solflare Wallet (solflare.com)

Test 1: Phantom Wallet Connection

Test Case 1.1: Connect Phantom Wallet

Steps:
  1. Open the Gorweld website in the test frame below
  2. Click the "Connect Wallet" button in the navigation bar
  3. Select "Phantom" from the wallet selection modal
  4. Approve the connection request in the Phantom wallet popup
Expected Result:
✓ Wallet selection modal closes
✓ "Connect Wallet" button is replaced with truncated wallet address
✓ Wallet address is displayed in format: "ABC...XYZ" (first 3 and last 3 characters)
✓ Dropdown arrow appears next to address

Test Case 1.2: Disconnect Phantom Wallet

Steps:
  1. With Phantom wallet connected, click on the wallet address display
  2. Click "Disconnect" from the dropdown menu
Expected Result:
✓ Dropdown menu closes
✓ Wallet address display is replaced with "Connect Wallet" button
✓ Wallet state is cleared from localStorage

Test Case 1.3: Phantom Wallet - User Rejection

Steps:
  1. Click "Connect Wallet" button
  2. Select "Phantom" from the modal
  3. Click "Cancel" or "Reject" in the Phantom wallet popup
Expected Result:
✓ Error message displayed: "Connection request was cancelled"
✓ User can retry connection
✓ No error thrown in console

Test Case 1.4: Phantom Wallet - Not Installed

Steps:
  1. Disable or uninstall Phantom wallet extension
  2. Click "Connect Wallet" button
  3. Select "Phantom" from the modal
Expected Result:
✓ Error message displayed with installation instructions
✓ Link to phantom.app provided
✓ Modal remains open for user to try another wallet

✓ UI updates correctly each time
