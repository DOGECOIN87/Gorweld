Requirements: 5.1, 5.2, 5.3, 5.4, 5.5

Prerequisites: You must have already submitted at least one card using the connected wallet to test editing functionality.

Test 1: Loading Existing Card for Editing

Test Case 1.1: Detect Existing Card

Steps:
  1. Connect wallet that has previously submitted a card
  2. Observe the "Submit Your Project" button
Expected Result:
✓ Button text changes to "Edit Your Card" or shows edit option
✓ System detects existing card for connected wallet
✓ Edit option is clearly visible

Test Case 1.2: Load Existing Card Data

Steps:
  1. Click "Edit Your Card" button
  2. Wait for modal to open
  3. Observe form fields
Expected Result:
✓ Configuration modal opens
✓ All fields populated with existing card data
✓ Project name matches published card
✓ Subtitle matches published card
✓ Description matches published card
✓ URL matches published card
✓ Icon matches published card
✓ Media files shown in list
✓ Preview shows current card state

Test Case 1.3: No Card Exists

Steps:
  1. Connect wallet that has NOT submitted a card
  2. Check button state
Expected Result:
✓ Button shows "Submit Your Project"
✓ No edit option available
✓ Opens empty form when clicked

Steps:

Expected Result:
✓ Last save wins (Tab 2 overwrites Tab 1)
✓ No data corruption
✓ Card shows Tab 2 changes
✓ (Optional: Warning about concurrent edits)

Test Case 5.4: Edit with Minimal Changes

Steps:

Expected Result:
✓ Minimal change saved successfully
✓ No issues with small updates
✓ Card updates correctly
