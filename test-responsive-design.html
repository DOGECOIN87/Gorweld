🛠️ Browser DevTools Testing Guide

Chrome DevTools

Steps:
  1. Press F12 or Ctrl+Shift+I (Cmd+Option+I on Mac)
  2. Click the device toolbar icon (Ctrl+Shift+M)
  3. Select device from dropdown or enter custom dimensions
  4. Test different devices: iPhone 14 Pro, iPad, Galaxy S23, etc.
  5. Toggle between portrait and landscape
  6. Use throttling to simulate slow networks

Firefox Responsive Design Mode

Steps:
  1. Press Ctrl+Shift+M (Cmd+Option+M on Mac)
  2. Select device or enter custom size
  3. Test touch simulation
  4. Check different DPR (Device Pixel Ratio) values

Safari Responsive Design Mode

Steps:
  1. Enable Develop menu: Safari > Preferences > Advanced > Show Develop menu
  2. Develop > Enter Responsive Design Mode
  3. Select iOS devices
  4. Test with actual iOS simulators if available
