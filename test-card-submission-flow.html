⚠️ Important: These tests involve real SOL transactions on devnet/mainnet. Ensure you're testing on devnet or have test SOL available. The submission fee is 1 SOL.

Test 1: Complete Submission Flow (Happy Path)

Test Case 1.1: Full End-to-End Submission

Steps:
  1. Open Gorweld website
  2. Click "Connect Wallet" and connect any wallet
  3. Scroll to "Submit Your Project" section
  4. Click "Submit Your Project" button
  5. Fill in all required fields:
    • Project Name: "Test Project"
    • Subtitle: "A test project for QA"
    • Description: "This is a test project to verify the card submission flow works correctly."
    • Project URL: "https://example.com"
    • Select an icon (any)
    • Upload 1-2 test images (PNG/JPG, under 5MB)
  6. Verify live preview updates as you type
  7. Click "Pay & Publish (1 SOL)" button
  8. Review payment details in confirmation modal
  9. Click "Confirm Payment"
  10. Approve transaction in wallet
  11. Wait for transaction confirmation
  12. Observe success message
  13. Close modal and scroll to projects section
Expected Result:
✓ Configuration modal opens when button clicked
✓ All form fields accept input correctly
✓ Live preview updates in real-time
✓ "Pay & Publish" button enables when form is valid
✓ Payment modal shows correct amount (1 SOL)
✓ Payment modal shows correct recipient address
✓ Payment modal shows user's current balance
✓ Transaction processes successfully
✓ Success message displays with transaction link
✓ New card appears in projects section
✓ Card appears in chronological order (after existing cards)
✓ Card displays all entered information correctly
✓ Card media carousel works
✓ Card "Visit Project" button links to correct URL
